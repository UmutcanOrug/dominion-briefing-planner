Dominion Briefing Planner 1.0.0 adds an RTS-style scene briefing editor for Foundry VTT 13, with a guarded Lock View 2.1.x integration and English/Turkish UI.

- Six ordered actions: camera, portrait dialogue, tactical ping, tile visibility, delay and view locks.
- Scene-specific saved plans, speaker presets, JSON import/export and local preview.
- GM Play/Pause/Resume/Next/Stop, signed targeted commands, readiness timeouts and cleanup/recovery snapshots.
- Native Forge-compatible asset picker; no Lancer Communicator dependency.

**Forge install manifest:**

```text
https://github.com/UmutcanOrug/dominion-briefing-planner/releases/latest/download/module.json
```

Install through The Forge Bazaar's **Install from Manifest**, then enable **Lock View** (`LockView`, minimum 2.1.0) and **Dominion Briefing Planner** in your world. In Lock View, enable camera locks for the participating users. Open the planner with the satellite-dish tool under Token Controls.

**Validation:** 16 automated tests passed, manifest/import/localization checks passed, EN/TR browser fixture checked, ZIP independently extracted and verified. **Live Foundry V13/Forge multiplayer testing has not been run** because no running licensed instance was available. [Test report](https://github.com/UmutcanOrug/dominion-briefing-planner/blob/main/docs/TESTING.md).

**v1 limits:** camera moves are instant (0.05–3 zoom); Previous is disabled; local preview skips tile writes; live tile changes are scene-wide; reconnecting recipients need a restarted briefing. [Usage and limitations](https://github.com/UmutcanOrug/dominion-briefing-planner#readme).

Assets: `module.json` for manifest installation, `dominion-briefing-planner.zip` for the complete module, and `SHA256SUMS.txt` for integrity verification. GitHub's autogenerated source archives are not the module installation ZIP.
